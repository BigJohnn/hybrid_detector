03

不确定度被系统性低估 部分修复

协方差取 inv(JᵀJ)，残差按假设 anchor_sigma_px = 0.3 归一化—— 数学上成立，但前提是那个 σ 是对的。实测中位重投影 RMSE 1.261 px 意味着 χ²/dof ≈ 17.6，σ 应放大约 4.2×。 A1 已把方差因子 2·cost/dof 乘进协方差，并把它作为 variance_factor 暴露出来；README 上那两个 σ 已撤稿。

但只修了一半。方差因子能给噪声尺度定价，给不了独立性定价： 198 个边样本散布在约 15 条物理边界上，远不是 198 次独立观测。合成真值上 |dt|/σ 仍是 1.98（近）/ 2.37（远）， 标定良好应在 0.9 附近。剩下这 2× 要靠相关性建模，不能再靠残差自我申报。

重遮挡下颜色会盖过锚点几何 新 · 阻塞 A

60% 遮挡时 37 帧里有 7 帧错到 15 mm 以上，看上去像"边样本太少把位姿拽偏了"。 不是。决定性的一帧是 pose 26：涂装模型找到 0 条边， 仍然错 67.86 mm；同一张图用去漆模型读，错 2.38 mm。没有边，两边都是纯锚点解，区别只剩哪个 PnP 假设胜出。

pose 39 是 145.67 mm vs 纯锚点 2.93 mm；胜出假设的锚点方差因子是 21.4（≈1.4 px RMS，假设值 0.3 px），而纯锚点管线的胜出假设是 1.37。 即：在一个大部分被挡住的靶标上算出来的颜色分，压过了拟合良好的角点， 选错了单锚点位姿二义性的分支，随后边细化忠实地把错答案打磨得更精确。

结论：增益成立，且不止一个域。 远距大倾角 p90 19.10 mm vs 去漆 60.75 mm（−68.6%，solved 60/60 不变）； 50% 遮挡 + anchor-free p90 5.13 vs 14.78（−65%，solved 55 vs 53，反而更多）。
但先修好渲染器再信任何合成数字： render_carrier 原本把每张 ArUco 一律贴在 quadrant 0，而 0907 描述符把 paste_quadrant 钉死在 3/3/2，检测器又按钉死值读、不搜索—— 渲染器把码贴在了检测器不被允许去看的地方。误差 150–370 mm、48–142°， 而且照样 success=True。0904 描述符不钉 quadrant，整个测试套件用的都是 0904， 所以从来没有暴露。真实采集不受影响。已修，并补了一条没有该修复就差 280 mm 的回归测试。

目的
找出彩色 facet 相对同体去漆基线真正获胜的操作域。找不到，路线 A 取消。
关键
基线必须是同一个体、剥掉漆，不是另一个靶标——否则比的是几何不是漆。 注意 --strip-paint 是就地修改指定的 --target，不会额外生成一行， 所以同一个模型文件要用两个 label 传两次。
动作
四组扫描，共用同一批位姿、同一相机、同一噪声（--seed 7 固定）： 
# 公共前缀：同体配对 + 真实锚点布局做第三方参照
M=assets/models/hybrid_carrier_v1_20260907.json
L=assets/models/hybrid_carrier_v1_20260907_marker_layout.json
BASE="--target painted=$M --target plain=$M --strip-paint plain \
      --layout rig=$L --poses 60 --seed 7"

# a) 遮挡扫描 —— 信息分散在 31 条边 vs 集中在 3 个锚点
python -m hybrid_detector.cli.compare_targets $BASE \
  --obstruction-sweep 0 0.15 0.30 0.45 0.60 \
  --out outputs/ab/obstruction.json

# b) 曝光拖影 —— 糊掉的锚点角点 vs 糊掉的漆边
python -m hybrid_detector.cli.compare_targets $BASE \
  --motion-sweep-mm 0 1 2 4 8 --motion-lever-mm 300 \
  --out outputs/ab/motion.json

# c) 远距离 + 大倾角 —— 锚点像素面积塌缩的regime
python -m hybrid_detector.cli.compare_targets $BASE \
  --distance-m 0.9 2.2 --tilt-deg 50 \
  --out outputs/ab/range.json

# d) 全锚点遮挡 —— 只有涂装靶标能作答，rig 直接失败
python -m hybrid_detector.cli.compare_targets $BASE \
  --allow-anchor-free --obstruction-sweep 0.5 0.7 \
  --out outputs/ab/anchorfree.json
判据
预先声明，不许事后改：至少一个操作域里，painted 相对 plain 的 p90（|dt| 90 分位，mm）降低 ≥ 30%，且 n（solved 数）不下降。 输出表列名即 n fail p50 p90 max drot anc edge。
警告
这是理想针孔、无畸变、高斯噪声的合成渲染。它只能证伪，不能证实—— 给的是"上界下的相对比"。通过了必须在 A2 用真实图像复现，才算数。
交付
四个 JSON + 一张"增益 vs 工况"曲线图 + 一句话结论：赢在哪个域，赢多少。

补检 MBT 一族在先技术

第 1–2 周 · 喂给 T0.2 的律师

问题
现有自评只比了平面 fiducial（ChromaTag / STag / AR-HueCode / RUNE-Tag）。 但 method.md 第 3–6 步——粗位姿投影 CAD、沿投影法向一维搜索边界、点到线残差 + 鲁棒核联合优化—— 就是 model-based 3D edge tracking 的标准配方，这一族一篇都没引。
必补
  • Harris & Stennett, RAPiD (1990) —— 法向一维搜索 + 点到线残差的源头
  • Drummond & Cipolla, TPAMI 2002 —— 鲁棒 M-estimator 版
  • Comport / Marchand / Chaumette, TVCG 2006 —— ViSP MBT，至今仍是现成开源基线
  • Petit / Marchand / Kanani, ICRA 2014 —— edge + keypoint + colour 联合，与第 3–5 步重合度最高
  • Wuest et al., ISMAR 2005 —— 多假设自适应线跟踪
结论
这不意味着不能发或不能申，而是新颖性落点必须从 "predict-project-test" 上移开—— 那个结构 1990 年就有了。落点移到双尺度分解与可观测性准入。

第 2 周末

T0.1 是否找到了增益域？已判定 · 走 A

A0

定死证据层级新 · 阻塞

第 3 周 · 阻塞 A3 之后的一切 · 这是一个设计决定，不是一个常数

问题
见 §0 第 04 条：重遮挡下颜色分压过锚点几何，选错单锚点位姿二义性的分支。 这不是"边太少"，pose 26 在零条边的情况下就已经错 67.86 mm。
要答的
颜色证据在什么条件下有资格推翻已解码的角点？ 我的意见是：永远不能单独推翻。假设排序应当有一条锚点证据地板—— 胜出假设的锚点残差不得显著劣于同批次最好的那个——颜色只在锚点无法分辨时打破平局。 但这条写进代码就是论文里"证据契约"的核心，值得你自己拍板而不是我替你定。
顺带
把 edge_constraints_span_the_pose、信任半径、σ 准入 从 if anchor_free: 里搬出来，让有锚点的路径也过闸；失败时回退到纯锚点解、 而不是判帧失败。并修掉 detector.py:2258 那条与代码不符的注释。
反面教材
已经试过一版"σ 相对准入"（细化后 σ 不得大于纯锚点 σ）并回退了： 在同一个错假设上算出来的基线本身就差，细化确实让它变精确，闸门永远不触发。 离线看着有效，是因为那次比的是两条不同的管线——那不是检测器能对自己做的检验。
判据
60% 遮挡下 painted 的 p90 回到 plain 之下（当前 50.40 vs 14.52）， 且远距工况的 −68.6% 增益不被削掉。两个条件必须同时成立。
A1

修协方差缩放已完成一半

2026-09-10 执行 · 剩下的一半是相关性，不是尺度

方差因子 2·cost/dof 已乘进 solve_carrier_pose 与 estimate_build_scale 的协方差，variance_factor 已作为字段暴露。 合成数据上这个因子是 0.25–0.42（渲染噪声比假设的干净，σ 反而缩小）， 真实台架上按 1.261 px 推算接近 17（σ 放大约 4×）。 但 |dt|/σ 仍是 2 左右：方差因子给不了独立性定价， 198 个边样本串在约 15 条边界上远不是 198 次独立观测。这 2× 得靠相关性模型。
连带影响：anchor_free_max_sigma_m = 0.004 现在比的是一个被缩放过的 σ， 合成上闸门变松（solved 52→55），真实数据上会变紧约 4×。这个常数必须在真实数据上重标。

动作
在 solve_carrier_pose（detector.py:1345）里把 inv(JᵀJ) 乘上残差方差缩放 s² = χ²/(m−6)，并把 χ²/dof 一并写进 PoseSolution 与报告 JSON。
顺带
把 anchor_sigma_px 从假设值改为实测：拿静止序列的角点抖动标定它。 现在的 0.3 px 是个愿望。
交付
更新 README 与 validation.md 的所有 σ 数字；标注旧值为未缩放。
判据
报告的 σ 与外部真值（A3）的实测误差同量级。差 4× 就是还没修对。
加分
把"我们发现自报不确定度低估 4×并修正"写进论文——审稿人吃这套，这是诚实性信号。

A3

外部真值

第 5–8 周 · 依赖 A1 + A2 · 本路线唯一的重成本项

为什么排这么后
激光跟踪仪机时贵、排期长。先用 T0.1 + A2 确认值得花这笔钱，再花。
三选一
  • 激光跟踪仪（Leica AT960 / API）——最强，可溯源，~μm 级，贵
  • 高精度机器人重复定位——只给重复性不给准确度，便宜，够写一半

必做
真值系与相机系的手眼配准本身有误差，必须单独报告其不确定度， 不能混进检测器误差里。这是审稿人第二个会问的问题。
交付

判据

  • ViSP MBT —— 关键。T0.3 那一族的现成实现，不比它，审稿人会替你比
  • 可选：一个学习式位姿基线（如 CNOS / MegaPose 类），说明非学习方法的定位
公平性
面积匹配、印刷匹配、标定匹配、算力预算匹配。任何一项不匹配都要在正文写明。
交付
误差 vs 工况的曲线族，外加运行时分布（中位 / P95 / 硬件型号）。
A6

跨条件稳健性

第 10–12 周

维度
跨天（标定漂移）、跨光照（色温 / 强度 / 阴影）、跨打印批次、跨镜头、跨载体个体（至少 2 个物理件）、拆装重复性（socket 取下再装回）。
重点
跨光照是涂装靶标的软肋，也是审稿人最会攻击的点——颜色分类在色温漂移下还成立吗？ 代码里颜色参考取自锚点黑白区（colour_reference_from_anchors），这是个好设计， 要把它作为卖点量化：给出"用锚点自参考 vs 用全局固定阈值"的对比。
判据
冻结参数，不许每个条件单独调参。调了就要报告。
A7

失败案例与预注册

第 12 周

动作
把 detect_carrier 已有的失败分类学（无锚点解码 / 无一致假设 / facet 不足 / 边样本不足 / 边几何欠约束 / 仅锚点解 / 联合解） 统计成一张分布表，配典型失败图。这套分类学是现成的资产，别浪费。
预注册
所有排除阈值、剔除规则、异常帧定义写进论文，且必须与 T0.1 事前声明的一致。 事后调阈值是这类论文最容易被抓的地方。
交付
失败分布表 + 排除规则清单 + 统计区间（bootstrap CI，不是只给中位数）。
A8

成稿与投稿

第 13–14 周

叙事
标题层面就是一件器具：co-designed 靶标 + 证据感知估计器 + 完整的不确定度契约。 不要写成"我们提出了一种新的 fiducial"。
三个卖点
  • 双尺度分解（body vs marker）——误差源分解，TIM 的正中靶心
  • 拟合前可观测性准入——拒绝退化解，而不是事后看残差
  • 修正后的不确定度契约——自报 σ 与外部真值一致
投

放行

§5

路线 B · 基准方法论论文

第 3–8 周 · 目标 ISMAR

如果增益不成立，不要硬写检测器论文。把主张换成 compare_targets.py 里那套对比范式本身—— 它解决的是一个真问题："两个不同的靶标，怎么才算公平地比过一次？" 现有 fiducial 文献在这件事上相当粗糙，这是个真空。

B1

把 harness 提成基准

第 3–5 周

动作
从 CLI 抽出稳定的基准接口：固定位姿集、固定噪声模型、版本化的 schema （已有 hybrid_detector/fiducial_target_ab/v1，是个好起点）、可复现的种子。
补
把理想针孔换成可选的真实畸变模型，否则"合成即上界"的批评无法回应。
B2

错模型定价作为核心贡献

第 3–5 周 · 与 B1 并行

为什么这是核心
render[:detect] ——用错的模型去解正确渲染的图—— 把"几何误差值多少毫米"变成一个可测量的数，而不是用同一个模型渲染又检测、把问题定义掉。 据我所知这个做法在 fiducial 文献里没有被系统提出过。这一条比检测器本身更好发。
展开
系统地给几类几何误差定价：打印缩放误差、as-built vs 名义 CAD、贴纸旋转误差、 标定内参误差。每一类给出"误差量 → 位姿误差"的传递曲线。
并入
双尺度分解在这里作为"错模型定价"的一个应用案例出现，不是独立主张。
B3

收录公开靶标

第 5–7 周

动作
把 3–5 个公开靶标接进同一 harness：ArUco、AprilTag 3、ChArUco、STag、（可选）ChromaTag。 混合载体作为其中一个被测对象出现，不是主角。
价值
产出一张"遮挡 / 拖影 / 距离 / 倾角"四维下的靶标选型表—— 这是一个所有做机器人视觉的人都想要、但现在没有的东西。
交付
开源基准（在专利受理之后）+ 选型表 + 复现脚本。

按匹配度，非按影响因子
档去向为什么怎么框
一档 IEEE TIM 首选。TIM 的口味就是"测量系统 + 不确定度分析 + 可溯源真值 + 误差源分解"。双尺度分解、χ²/dof、失败分类学、provenance 绑定，在 CV 会议是工程细节，在这里是正文贡献。 一件 6-DoF 位姿测量器具
一档 IEEE RA-L 滚动投稿、8 页、系统类友好、一轮约 2 个月。可挂 ICRA/IROS 宣讲。适合抢时间先占位。 机器人 TCP / 宽基线位姿测量
二档 ISMAR fiducial marker 的发源社区（ChromaTag / STag / Wuest）。路线 B 的首选。 靶标设计 + 对比方法论
二档 IROS / ICRA fiducial 系统类论文的常规去处，接受度远高于顶级视觉会议。 机器人感知系统
二档 TMech / RCIM 若重心落在工业机器人标定应用而非视觉方法。 工业机器人标定
三档 Measurement · IEEE Sensors J. 比 TIM 低一档的稳妥退路，选题口味接近。 同 TIM
三档 Sensors (MDPI) 快、开放获取，但档次与口碑都低。只在需要抢时间时考虑。 —
不建议 CVPR / ICCV / ECCV 非学习类 fiducial 论文近年基本进不去。ChromaTag 那个窗口（ICCV 2017）已经关了。 —
不建议 IEEE T-RO 除非把可观测性准入做成真正的理论贡献（信息矩阵条件数的可证界、退化流形刻画），否则理论深度与实验量都不够。 —
§7

风险登记

触发信号 → 应对
风险触发信号应对
合成对照本身是坏的 渲染器与检测器对同一个描述符的读法不一致 已发生一次。贴纸 quadrant 那次错了 150–370 mm 还报 success，因为 render/detect 自洽而不正确。凡合成台架，必须至少有一条断言打在外部已知位姿上；每加一个描述符字段，先问渲染器认不认它。
颜色压过锚点 遮挡加大时 painted 的尾部反超 plain 已发生（60% 遮挡，p90 50.40 vs 14.52）。见 A0：假设排序要有锚点证据地板。论文里这条要主动写——它正好是"证据契约"主张的反例与修复，审稿人比你更容易想到它。
合成赢、真实不赢 A2 的增益方向与 T0.1 不一致 回 G1 重判。多半是真实印刷质量 / 光照把颜色闸门的优势吃掉了；先查 colour_reference_from_anchors 在该数据上的稳定性。
被 ViSP MBT 打平 A5 中 ViSP 与 full 方法误差相当 主张退到"免手工初始化 + 免逐场景调参 + 自带可观测性拒绝"，即工程可靠性而非精度。仍可发，但要换标题。
真值系统排不上期 A3 超过第 8 周仍未开始 退到"机器人重复定位 + 精密转台"，只声称重复性与相对精度，明确写出不声称绝对准确度。论文降一档投但不停摆。
专利被 EP2157545 / US9526587 挡住 T0.3 的比对表显示装置权项要素被全覆盖 放弃宽装置权项，集中到双尺度分解方法权项 —— 它与那两族的技术问题不同（制造偏差归因，非识别）。T0.3 已把更大的一族补进来：RAPiD 1990 / Drummond–Cipolla 2002 / ViSP 2006 / Petit 2014 / PWP3D，method.md 第 3–6 步整段是在先技术。
